# GRE Roots

手機優先的 GRE Roots 字根背誦 App。使用者可以自由選擇第 1–5 份，以 Flashcard 翻面學習，並用「還不熟／有點模糊／記住了」標記記憶程度。

## 分類規則

原始資料共 2,078 字，包括 538 個一般字根家族與 464 個無字根（S）單字。新版五份使用下列規則：

1. 同一字根家族永遠放在同一份，不拆散相關單字。
2. 字根家族數配成 `108 / 108 / 108 / 107 / 107`。
3. 先以家族單字量做負荷平衡，再用 S 單字補齊每份總量。
4. 最終單字量為 `416 / 416 / 416 / 415 / 415`。
5. S 單字平均穿插在字根家族之間，避免集中成難以背誦的大區塊。

| Part | 字根家族 | 有字根單字 | S 單字 | 總單字 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 108 | 324 | 92 | 416 |
| 2 | 108 | 323 | 93 | 416 |
| 3 | 108 | 323 | 93 | 416 |
| 4 | 107 | 322 | 93 | 415 |
| 5 | 107 | 322 | 93 | 415 |

## 功能

- 五份學習卡自由選擇
- 正反面 Flashcard：音標、中文、英文定義、例句與字根
- 卡片背面將來源中的同義字、反義字與記憶提示分開呈現，資料檢查會確認每段 `[類]` 同義字完整保留
- 進入每張卡會優先播放 Wiktionary／Wikimedia Commons 的真人錄音：先選美式英語，再選其他英語口音；完全找不到授權清楚的真人錄音時才使用 AI／裝置合成語音
- 可選擇翻到解釋時是否自動播放中文發音，設定保存在目前裝置，亦可在卡片背面手動播放
- 中文主解釋與教育部《國語辭典簡編本》詞目完全相同時，播放未修改的官方詞目全文真人錄音；其餘使用裝置的繁體中文語音
- 教育部錄音會預載目前字卡與後面十個單字；英文真人錄音會預載目前字卡與後面二十個單字。遠端真人錄音無法播放時會立即切換 AI／裝置合成語音
- 字卡自動連播：每張先看單字、後半自動翻面，可選 3–30 秒停留時間並隨時暫停
- 首頁與每份字卡顯示背誦進度，包括已背、剩餘、總字數與完成百分比
- 使用 ChatGPT 帳號登入；新帳號先進入待審核，核准後才能讀取單字與發音資料
- 管理員可在 App 內核准、拒絕或撤銷帳號；指定管理員帳號受到保護，無法被撤銷
- 全部／待複習／已記住篩選
- 單字、中文意思與字根搜尋
- 字根家族快速切換、隨機排序、左右滑動
- App 不另設密碼，登入由 ChatGPT 處理
- 背誦進度仍保存在目前裝置；帳號審核狀態儲存在 Sites 資料庫

## 開發

```bash
pnpm install
pnpm dev
```

完整檢查：

```bash
pnpm check
```

若要從 Excel 重新產生資料，預設會讀取專案上一層的最終工作簿；也可指定路徑：

```powershell
$env:GRE_SOURCE_XLSX = "C:\path\to\workbook.xlsx"
pnpm run data:export
```

GRE 單字資料的原始 PDF、工作簿與密碼不會納入此 repository。

## 英文真人錄音來源

英文真人錄音取自 Wiktionary 英文詞頁列出的 Wikimedia Commons 錄音。匯入程式只接受 Commons 檔案頁提供完整作者與授權資料、而且已有官方 MP3 轉碼的錄音；播放時依序選擇明確美式英語、其他英語口音，並在介面顯示錄音者、來源與授權。本次匯入涵蓋 2,055 個不重複單字中的 2,002 個：1,086 個美式真人錄音及 916 個其他英語口音真人錄音，剩下 53 個使用 AI／裝置合成語音。

網站只保存官方 MP3 網址與授權紀錄，不大量複製 Commons 音檔；瀏覽器會預載目前需要的錄音。重新掃描並驗證：

```bash
pnpm run english:import
pnpm run english:validate
```

## 中文真人錄音來源

中文真人錄音取自中華民國教育部《國語辭典簡編本》`dict_concised_music_www_2014_20260626` 詞目全文聲音檔，依「創用 CC－姓名標示－禁止改作 3.0 臺灣」授權使用。匯入程式只挑選與中文主解釋完全相同的詞目，並保留原始 WAV，不轉檔、不裁切、不調速。完整使用說明隨錄音保存在 `public/audio/moe/conciseddict_10312.pdf`。

重新匯入固定版本的官方資料與錄音：

```bash
pnpm run mandarin:import
pnpm run mandarin:validate
```
